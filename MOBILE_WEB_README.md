# 📱 Мобильная веб-версия с FaceID

Дополнительная мобильная веб-версия MARK L с аутентификацией по распознаванию лица владельца.

## 🌟 Возможности

- **FaceID вход** - доступ только для зарегистрированного владельца
- **Мобильный интерфейс** - оптимизирован для телефонов
- **Персонализация** - показывает имя владельца и ассистента
- **Быстрые действия** - доступ к основным функциям
- **Регистрация лица** - можно зарегистрировать лицо прямо с телефона

## 🚀 Как использовать

### 1. Доступ к мобильной версии

**Вариант A: Через основную страницу логина**
- Откройте `http://<IP-адрес>:8000/login` на телефоне
- Нажмите на ссылку "📱 Мобильная версия с FaceID"

**Вариант B: Прямой URL**
- Откройте `http://<IP-адрес>:8000/mobile` на телефоне

### 2. Регистрация лица (первый вход)

Если нет зарегистрированных лиц:
1. Нажмите кнопку **"ЗАРЕГИСТРИРОВАТЬ ЛИЦО"**
2. Введите ваше имя
3. Посмотрите в камеру и нажмите подтвердить
4. Лицо будет сохранено в `config/faces/<ВашеИмя>/`

### 3. Вход по FaceID

1. Откройте мобильную версию
2. Нажмите **"СКАНИРОВАТЬ ЛИЦО"**
3. Посмотрите в камеру
4. Система проверит лицо с базой `config/faces/`
5. При успешном распознавании откроется основной интерфейс

### 4. Добавление лица вручную

Также можно добавить фото вручную:
```bash
# Создайте папку с именем владельца
mkdir config/faces/Иван

# Скопируйте несколько фото лица (3-5 штук)
cp photo1.jpg config/faces/Иван/
cp photo2.jpg config/faces/Иван/
cp photo3.jpg config/faces/Иван/
```

FaceID система автоматически обучится на этих фото.

## 🔒 Безопасность

- **FaceID аутентификация** - только зарегистрированные лица получают доступ
- **LBPH распознавание** - локальное распознавание без отправки данных в облако
- **YuNet детектор** - точное обнаружение лиц даже в сложных условиях
- **Порог совпадения** - 72% (настраивается в `actions/face_id.py`)

## 🎨 Интерфейс

### Экран входа
- Круглая видео-область с анимацией сканирования
- Кнопка сканирования
- Статус распознавания
- Кнопка регистрации (если нет лиц)

### Основной интерфейс (после входа)
- Приветствие с именем владельца
- Бейдж с именем ассистента
- Быстрые действия (Камера, Поиск, Файлы, Настройки)
- Статус системы

## 📊 API Endpoints

### GET /api/face-auth/status
Проверка статуса FaceID системы.

**Ответ:**
```json
{
  "ok": true,
  "has_faces": true,
  "enrolled_count": 1,
  "enrolled_names": ["Nick Fury"],
  "detector": "yunet",
  "user_name": "Nick",
  "assistant_name": "EDIT"
}
```

### POST /api/face-login
Аутентификация по лицу.

**Запрос:**
```json
{
  "frame": "base64_encoded_jpeg"
}
```

**Ответ (успех):**
```json
{
  "ok": true,
  "authenticated": true,
  "user_name": "Nick",
  "assistant_name": "EDIT",
  "face_label": "FACE — NICK FURY",
  "confidence": "match 85%",
  "token": "session_token"
}
```

**Ответ (отказ):**
```json
{
  "ok": true,
  "authenticated": false,
  "error": "Лицо не распознано. Доступ только для владельца."
}
```

### POST /api/face-enroll
Регистрация нового лица.

**Запрос:**
```json
{
  "frame": "base64_encoded_jpeg",
  "name": "Иван"
}
```

**Ответ:**
```json
{
  "ok": true,
  "message": "Лицо 'Иван' зарегистрировано"
}
```

## 🔧 Технические детали

### Зависимости
- **OpenCV** - обработка изображений и распознавание лиц
- **YuNet** - нейросетевой детектор лиц
- **LBPH** - алгоритм распознавания лиц (локальный, быстрый)

### Файлы
- `dashboard/static/mobile.html` - мобильный веб-интерфейс
- `dashboard/server.py` - API endpoints для FaceID
- `actions/face_id.py` - движок распознавания лиц
- `config/faces/` - папка с зарегистрированными лицами
- `config/api_keys.json` - имена владельца и ассистента

### Совместимость
- Работает на всех современных мобильных браузерах
- Требует доступ к камере (getUserMedia API)
- Для HTTP (не HTTPS) может потребоваться настройка браузера:
  - Chrome: `chrome://flags` → "Insecure origins treated as secure"

## 💡 Советы

1. **Качество фото при регистрации**
   - Используйте хорошее освещение
   - Лицо должно быть хорошо видно
   - 3-5 фото с разных ракурсов улучшают точность

2. **Порог распознавания**
   - По умолчанию: 72% (в `actions/face_id.py`)
   - Уменьшите для более строгой проверки
   - Увеличьте для более мягкой проверки

3. **Производительность**
   - YuNet работает быстрее на GPU
   - Haar cascade - fallback для слабых систем
   - Первое сканирование может занять 1-2 секунды

## 🐛 Решение проблем

**Камера не работает**
- Разрешите доступ к камере в настройках браузера
- Для HTTP добавьте сайт в "Insecure origins treated as secure"

**Лицо не распознается**
- Убедитесь, что лицо зарегистрировано
- Добавьте больше фото в `config/faces/<Имя>/`
- Проверьте освещение и угол камеры

**Ошибка "FaceID недоступен"**
- Установите OpenCV: `pip install opencv-python`
- Проверьте, что `config/face_detection_yunet.onnx` существует

## 📲 Установка EDIT на телефон как приложения (PWA)

Remote Dashboard — устанавливаемое веб-приложение (PWA): после установки на телефоне появляется **иконка EDIT на главном экране**, приложение открывается в полноэкранном окне и работает быстрее.

### Android (Chrome)
1. Откройте Remote Dashboard на телефоне (сначала отсканируйте QR из **Remote Control** — после первого сканирования телефон запоминается автоматически).
2. Нажмите кнопку **⤓** в шапке приложения (появляется, когда приложение можно установить), либо меню браузера **⋮ → «Добавить на главный экран» / «Установить приложение»**.
3. Подтвердите — на главном экране появится иконка **EDIT**. Запускайте её: панель откроется в отдельном полноэкранном окне. Обычно вход восстанавливается автоматически по сохранённому токену устройства.

### iPhone / iPad (Safari)
1. Откройте панель, затем **Поделиться (⤴) → «На экран "Домой"»**.
2. Добавьте — иконка EDIT появится на главном экране.

> 💡 Установленное приложение поддерживает всё: режим наушников (🎧), голосовой канал, EDITH-камеру, Holo Lab. В режиме наушников экран не гаснет (Wake Lock). Помните: это пульт — ПК должен быть включён и запущен.
