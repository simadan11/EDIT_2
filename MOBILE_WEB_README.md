# 📱 Мобильный доступ к LUMEN

Мобильный веб-интерфейс LUMEN из предшествующей версии (отдельное приложение
с входом по лицу) заменён **единым отзывчивым интерфейсом платформы**: он
корректно работает в браузере телефона, планшета и ПК.

## 🌟 Что есть сейчас

- **Один интерфейс на все устройства** — `http://<IP-ПК>:8090`
  (диалог, инструменты, память, система, настройки).
- **Отзывчивый дизайн** — узкая рейка и компактные карточки на телефонах.
- **Доступ через Cloudflare** (извне, по HTTPS) — см. `cloudflare/README.md`:
  скрипт `setup-remote-control.ps1` настраивает туннель за одну команду.
- **Безопасность** — опциональный Bearer-токен (`api.auth_token` в
  `config/lumen.json`): при его задании все запросы, включая интерфейс,
  требуют токен.

## 🚀 Как открыть с телефона

1. Убедитесь, что ПК и телефон в одной сети (или настроен туннель).
2. На телефоне откройте:
   - в локальной сети: `http://<IP-адрес-ПК>:8090`
   - через туннель: `https://lumen-remote.<ваш-sub>.workers.dev/?k=СЕКРЕТ`
3. Если задан `api.auth_token` — отправьте запрос с заголовком
   `Authorization: Bearer <токен>` (например, через прокси-страницу
   или сценарий).

## 📲 Установка как PWA (иконка на главном экране)

**Android (Chrome):** меню браузера → «Добавить на главный экран» →
подтвердить. **iPhone (Safari):** кнопка «Поделиться» → «На экран «Домой»».
Приложение откроется в полноэкранном окне и будет вести себя как нативное.

## 🧭 Дорожная карта мобильного модуля

- вход по лицу владельца (модуль face-auth) — возвращение возможности из
  предшествующей версии в новом виде;
- голосовой канал из телефона (стрим PCM в ядро);
- push-уведомления по результатам мониторинга.
