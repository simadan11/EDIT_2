# ◈ LUMEN — самостоятельная ИИ-платформа

**LUMEN (Люмен)** — «Свет, который понимает». Полностью самостоятельная
ИИ-платформа: собственное ядро **LUMEN-1**, собственный конвейер обработки
запросов **«Луч»**, модуль контекстной памяти, реестр инструментов и
обучающая петля. Проект создан заново по концепции и архитектуре — не
переименование и не копия предшествующих версий кодовой базы.

```
   ┌───────────── ЛУЧ: конвейер каждого запроса ─────────────┐
   │                                                         │
   │  ① ПРИЁМ ─▶ ② ЗАЩИТА ─▶ ③ АНАЛИЗ ─▶ ④ КОНТЕКСТ         │
   │      │            │             │             │         │
   │  нормализация  anti-injection  намерения     персона +  │
   │  лимиты, спам  уровни риска   слоты, план   факты +     │
   │                                           история       │
   │                                                         │
   │  ⑥ ГЕНЕРАЦИЯ ◀────── ⑤ ИНСТРУМЕНТЫ                      │
   │      │                    реестр, таймауты,             │
   │  LHC / Gemini /          изоляция ошибок                │
   │  OpenAI-совместимый                                           │
   └─────────────────────────────────────────────────────────┘
                 +  ЗАПОМИНАНИЕ (память и обучающая петля)
```

## Возможности

- **Ядро LUMEN-1** — детерминированный конвейер из шести стадий:
  приём, защита, анализ намерений, сборка контекста, исполнение
  инструментов, генерация ответа. Каждое событие конвейера видно в
  реальном времени (SSE).
- **Защитный слой** — нормализация, лимиты, анти-спам, обнаружение
  prompt-injection (RU/EN), уровни риска `safe / caution / blocked`.
- **Контекстная память** — три слоя: рабочая (сессия), эпизодическая
  (журналы), семантическая (факты по категориям). Автоизвлечение фактов
  из разговора («меня зовут…», «живу в…»), relevance-выборка,
  импорт памяти предшествующей версии без потерь.
- **Реестр инструментов** — декларативные схемы, таймауты, изоляция
  ошибок, честная доступность. Встроенные: `system.status`, `time.now`,
  `math.calc`, `weather.current`, `files.search`, `memory.recall`,
  `memory.store`, `knowledge.capabilities`. Legacy-мост подключает
  старые модули `actions/*` как инструменты `legacy.*`.
- **Генеративные модули (backends)** — переключаемые в настройках:
  - **LHC** — встроенный локальный модуль рассуждения (без сети и ключей);
  - **Gemini** — Google Gemini (REST);
  - **OpenAI-совместимый** — Ollama, LM Studio, Jan, llama.cpp, vLLM…
  Сбой сетевого модуля на лету деградирует на LHC с пометкой fallback.
- **Обучающая петля** — оценки ответов (👍/👎), адаптация предпочтений,
  статистика, экспорт корпуса «запрос → ответ → оценка» в JSONL
  — готовый датасет для future fine-tuning.
- **Интерфейсы** — веб (новый дизайн «Luminance»), CLI, REST/SSE API.
- **Наследственный десктоп** — голосовой PyQt-компаньон (`python main.py`)
  переименован в LUMEN и работает как режим «Desktop» поверх того же
  набора действий; основная точка входа — новая платформа.

## Быстрый старт

**Требования:** Python 3.9+. Платформа работает на чистой стандартной
библиотеке — обязательных зависимостей нет.

```bash
# 1. Платформа: веб-интерфейс + API
python -m lumen serve --port 8090
# → http://localhost:8090

# 2. Диалог в терминале
python -m lumen chat

# 3. Инструменты
python -m lumen tools
python -m lumen tools run math.calc --arg expression="2+2*3"

# 4. Состояние и память
python -m lumen status
python -m lumen memory show
```

Опционально (голос, legacy-модули, десктоп):

```bash
pip install -r requirements.txt   # тяжёлые зависимости legacy-режима
```

## Состав проекта

| Путь | Назначение |
|---|---|
| `lumen/` | **Новая платформа**: ядро LUMEN-1, инструменты, память, API, веб-интерфейс |
| `lumen/kernel/` | Конвейер «Луч»: `engine`, `safety`, `planner`, `context`, `backends`, `memory`, `tools`, `learning` |
| `lumen/web/` | Веб-интерфейс (дизайн «Luminance», нулевые зависимости) |
| `lumen/api/` | REST + SSE сервер (stdlib http.server) |
| `lumen/tools/` | Встроенные инструменты + legacy-мост к `actions/*` |
| `lumen_data/` | Рабочие данные: память, сессии, обучение (не коммитится) |
| `config/lumen.json` | Конфигурация платформы (создаётся автоматически) |
| `config/api_keys.json` | Legacy-конфиг (API-ключи); ключи импортируются в новый конфиг |
| `main.py`, `ui.py`, `hub.py` | Наследственный голосовой десктоп (режим «Desktop») |
| `actions/` | Модули действий — подключаются к ядру через legacy-мост |
| `memory/` | Legacy-менеджер памяти (источник импорта в новую память) |
| `tests/` | Тесты ядра и API (60 тестов, unittest) |
| `docs/` | Документация: архитектура, API, бренд-бук, roadmap, changelog |

## Конфиденциальность

- Память, сессии и обучение хранятся локально в `lumen_data/`.
- Сетевые запросы (погода — wttr.in, LLM-backends) идут только туда,
  куда вы указали в `config/lumen.json`; при `provider=heuristic`
  платформа не отправляет запросы наружу вовсе.
- Опциональный `api.auth_token` закрывает весь HTTP-интерфейс Bearer-токеном.
