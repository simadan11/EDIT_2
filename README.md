# ◈ LUMEN — самостоятельная ИИ-платформа

**LUMEN (Люмен)** — «Свет, который понимает». Полностью самостоятельная
ИИ-платформа, **полностью на собственном ИИ**: единственный генеративный
модуль **LUMEN Core** (база знаний, диалог, вычисления — офлайн, без
внешних API и ключей), конвейер обработки запросов **«Луч»**, модуль
контекстной памяти, реестр инструментов и обучающая петля. Внешних
LLM-модулей (Gemini, OpenAI и т.п.) в платформе нет. Проект создан
заново по концепции и архитектуре — не переименование и не копия
предшествующих версий кодовой базы.

```
   ┌───────────── ЛУЧ: конвейер каждого запроса ─────────────┐
   │                                                         │
   │  ① ПРИЁМ ─▶ ② ЗАЩИТА ─▶ ③ АНАЛИЗ ─▶ ④ КОНТЕКСТ         │
   │      │            │             │             │         │
   │  нормализация  anti-injection  намерения     персона +  │
   │  лимиты, спам  уровни риска   слоты, план   факты +     │
   │                                           история       │
   │                                                         │
   │  ⑥ ГЕНЕРАЦИЯ ◀────── ⑤ ИНСТРУМЕНТЫ                      │
   │      │                    реестр, таймауты,             │
   │  LUMEN Core (свой ИИ,   изоляция ошибок                │
   │  офлайн, без внешних API)                               │
   └─────────────────────────────────────────────────────────┘
                 +  ЗАПОМИНАНИЕ (память и обучающая петля)
```

## Возможности

- **Ядро LUMEN-1** — детерминированный конвейер из шести стадий:
  приём, защита, анализ намерений, сборка контекста, исполнение
  инструментов, генерация ответа. Каждое событие конвейера видно в
  реальном времени (SSE).
- **Защитный слой** — нормализация, лимиты, анти-спам, обнаружение
  prompt-injection (RU/EN), уровни риска `safe / caution / blocked`.
- **Контекстная память** — три слоя: рабочая (сессия), эпизодическая
  (журналы), семантическая (факты по категориям). Автоизвлечение фактов
  из разговора («меня зовут…», «живу в…»), relevance-выборка,
  импорт памяти предшествующей версии без потерь.
- **Реестр инструментов** — декларативные схемы, таймауты, изоляция
  ошибок, честная доступность. Встроенные: `system.status`, `time.now`,
  `math.calc`, `weather.current`, `files.search`, `memory.recall`,
  `memory.store`, `knowledge.capabilities`. Legacy-мост подключает
  старые модули `actions/*` как инструменты `legacy.*`.
- **LUMEN Core — собственный ИИ платформы (основной модуль)** —
  локальный разум на чистом Python: работает офлайн, без ключей.
  - встроенная база знаний (100+ фактов: география, наука, математика,
    IT, история, повседневность) с офлайн-поиском;
  - диалоговое состояние: анафора («а в Киеве?» после вопроса о погоде,
    «а 5×7?» после вычисления) и составные запросы;
  - локальные вычислители: календарная математика («сколько дней до
    31 декабря?»), текстовая статистика (слова/знаки), калькулятор;
  - шутки и загадки; честный ответ, когда запроса нет в ядре.
- **Генеративный модуль** — один: **LUMEN Core** (см. выше).
  Внешних LLM-модулей нет — генерация всегда локальная: без API-ключей,
  без облака, без сети. Сетью пользуются только отдельные инструменты
  (погода — wttr.in): это данные, не ИИ.
- **Обучающая петля** — оценки ответов (👍/👎), адаптация предпочтений,
  статистика, экспорт корпуса «запрос → ответ → оценка» в JSONL
  — готовый датасет для future fine-tuning.
- **Самообучение каждую минуту** — фоновый цикл: LUMEN сам подхватывает
  новые факты из разговора («меня зовут…», «живу в…»), пересчитывает
  частые темы («фокус») и пишет heartbeat-журнал. Настраивается:
  `learning.auto_enabled`, `learning.auto_interval_sec`.
- **Мысли LUMEN** — на каждом шаге конвейера LUMEN ведёт видимую
  трассу рассуждений: что принял, какое намерение увидел, какие
  инструменты вызвал, как сгенерировал. Живая панель в чате, журнал
  в «Системе», API `GET /api/thoughts`.
- **Голос (без внешних API)** — 🔊 LUMEN отвечает голосом (движок TTS
  самого браузера, ru-RU), 🎤 можно диктовать сообщение голосом;
  «говорить ответы вслух» включается в настройках одним чекбоксом.
- **Интерфейсы** — веб (дизайн «Luminance»), настольная программа
  (`python -m lumen desktop`), CLI, REST/SSE API.
- **Наследственный десктоп** — голосовой PyQt-компаньон (`python main.py`)
  переименован в LUMEN и работает как режим «Desktop» поверх того же
  набора действий; основная точка входа — новая платформа.

## Быстрый старт

**Требования:** Python 3.9+. Платформа работает на чистой стандартной
библиотеке — обязательных зависимостей нет.

```bash
# 1. Платформа: веб-интерфейс + API
python -m lumen serve --port 8090
# → http://localhost:8090

# 2. Настольная программа (компаньон в стиле EDIT: лицо, диалог, голос)
python -m lumen desktop

# 3. Диалог в терминале
python -m lumen chat

# 4. Инструменты
python -m lumen tools
python -m lumen tools run math.calc --arg expression="2+2*3"

# 5. Состояние и память
python -m lumen status
python -m lumen memory show
```

Опционально:

```bash
pip install pyttsx3        # голос в настольной программе (TTS)
pip install -r requirements.txt   # тяжёлые зависимости legacy-режима
```

## Состав проекта

| Путь | Назначение |
|---|---|
| `lumen/` | **Новая платформа**: ядро LUMEN-1, инструменты, память, API, веб-интерфейс |
| `lumen/kernel/` | Конвейер «Луч»: `engine`, `safety`, `planner`, `brain` (LUMEN Core), `context`, `backends`, `memory`, `tools`, `learning` |
| `lumen/knowledge/` | Встроенная база знаний LUMEN Core (100+ фактов, офлайн-поиск) |
| `lumen/web/` | Веб-интерфейс (дизайн «Luminance», нулевые зависимости) |
| `lumen/api/` | REST + SSE сервер (stdlib http.server) |
| `lumen/desktop.py` | Настольная программа (tkinter, stdlib): диалог, мысли, голос |
| `lumen/tools/` | Встроенные инструменты + legacy-мост к `actions/*` |
| `lumen_data/` | Рабочие данные: память, сессии, обучение (не коммитится) |
| `config/lumen.json` | Конфигурация платформы (создаётся автоматически) |
| `config/api_keys.json` | Legacy-конфиг: ключи нужны только голосовому десктопу (режим «Desktop»), не платформе |
| `main.py`, `ui.py`, `hub.py` | Наследственный голосовой десктоп (режим «Desktop»; работает по стриминговому протоколу Gemini Live — legacy-опция, не ИИ платформы) |
| `actions/` | Модули действий — подключаются к ядру через legacy-мост |
| `memory/` | Legacy-менеджер памяти (источник импорта в новую память) |
| `tests/` | Тесты ядра, LUMEN Core, мыслей, самообучения и API (121 тест, unittest) |
| `docs/` | Документация: архитектура, API, бренд-бук, roadmap, changelog |

## Конфиденциальность

- Память, сессии и обучение хранятся локально в `lumen_data/`.
- Генерация — только LUMEN Core: полностью офлайн, без внешних
  API, без ключей, без сети. Из инструментов в сеть ходит только
  погода (wttr.in) — это данные, не ИИ.
- Опциональный `api.auth_token` закрывает весь HTTP-интерфейс Bearer-токеном.
