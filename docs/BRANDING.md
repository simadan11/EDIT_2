# ◈ Бренд-бук LUMEN

## Имя

**LUMEN** (рус. «Люмен») — единица светового потока в СИ. Метафора
продукта: платформа *освещает* — превращает хаос запроса в понятный
ответ, показывает путь конвейера (каждая стадия видна пользователю).

- Модель/ядро: **LUMEN-1** (конвейер «Луч»).
- Локальный модуль рассуждения: **LHC** (LUMEN Heuristic Core).
- Дизайн-система интерфейса: **Luminance**.
- Слоган: **«Свет, который понимает»** (EN: *The light that understands*).

Имя полностью самостоятельное: не является переименованием и не
перекликается с названиями предшествующих версий проекта.

## Логотип

`lumen/web/assets/logo.svg` — светящаяся линза-ромб в окружении восьми
лучей; градиент `#5EEAD4 → #818CF8`. Правила:

- минимальный размер 24×24 px; вокруг логотипа — «воздух» ≥ 8 px;
- на тёмных фонах — как есть; на светлых — контрастная версия
  (тёмные контуры);
- не вращать, не менять градиент на другие цвета.

## Типографика

- Основной: `Inter, "Segoe UI", -apple-system, Roboto, "Helvetica Neue", Arial`
  (системный стек — интерфейс не тянет веб-шрифты с CDN).
- Моноширинный (коды, метрики, имена инструментов):
  `"JetBrains Mono", "Cascadia Code", Consolas`.
- Заголовки: weight 750; надписи-категории: uppercase, letter-spacing 0.09em, 12 px.
- Базовый кегл 14.5 px, линия 1.55.

## Форма и структура

- Скругления: карточки 16 px, кнопки 10–12 px, чипы-пилюли 999 px.
- Панели: полупрозрачные (`rgba(148,163,215,.055)`) с тонкой рамкой
  `rgba(148,163,215,.14)`; активные состояния — впускное свечение.
- Карточка ответа LUMEN — **«lumina»**: шапка (логотип, имя, чипы
  интента/уверенности/модуля/латентности), тело (markdown), подвал
  (чипы инструментов + действия: 👍/👎, копировать, повтор).
- Ответ пользователя — правая «пузырь»-карточка с мягким градиентом.
- Индикатор обработки — три пульсирующие точки + живая подпись стадии
  конвейера («анализ намерений…», «инструмент: weather.current…»…).

## Голос (voice & tone)

- Спокойный, точный, тёплый. Без пафоса и без «ботиной» вежливости.
- Говорит на языке пользователя (по умолчанию русский).
- Честность как принцип: нет инструмента — говорит, чего не хватает;
  ошибка сети — называет её и предлагает путь.
- Коротко по умолчанию; развёрнуто — когда задача требует.
- Никогда не упоминает предшественников: LUMEN — самостоятельная
  платформа, у которой нет «до».
