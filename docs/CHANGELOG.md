# Changelog

## LUMEN 1.1 — «Полностью своё ИИ: LUMEN Core без внешних API»

Весь ИИ платформы — **LUMEN Core**, собственный локальный модуль.
Внешних генеративных API (Gemini, OpenAI-совместимые) в платформе
**нет вообще** — ни как основного модуля, ни как опционального
overflow. Генерация всегда офлайн, без ключей и без сети.

### Добавлено

- **`lumen/kernel/brain.py` — LUMEN Core**: единственный
  генеративный модуль (стадия 6 конвейера):
  - встроенная база знаний `lumen/knowledge/` — 117 фактов
    (география, наука, математика, IT, история, повседневность,
    о себе, юмор), офлайн-поиск со стем-толерантным сопоставлением;
  - диалоговое состояние: анафора («а в Киеве?», «а 5×7?» наследуют
    предыдущий план сессии) и составные запросы («сколько времени и
    как там система?»);
  - календарная математика («сколько дней до 31 декабря?», «через 30
    дней», «до Нового года»), текстовая статистика (слова/знаки в
    цитате, с правильными окончаниями);
  - намерения `knowledge`, `joke`, `riddle`, `date_math`, `text_ops`;
  - детерминированная вариативность формулировок; честный ответ,
    когда запроса нет в ядре.
- **`lumen_core` — единственный `backend.provider`**.
  UI: карточка «LUMEN Core — собственный ИИ (офлайн, без API)»
  вместо выбора модулей; поля ключа/модели/URL убраны.
- **`core/model_router.py` (legacy)** — по умолчанию маршрутизирует
  только в LUMEN Core; автоматических внешних вызовов нет (явные
  legacy-режимы `use_local_claude`/OSINT/`model=...` — выбор
  пользователя, как были).
- **Исправлено**: контекст генерации теперь получает текущее
  сообщение явно (раньше weave брал его из памяти, где оно
  записывается только после генерации — сетевые модули видели
  предыдущую реплику).
- **Тесты** `tests/test_lumen_core.py` — 46 новых (база знаний,
  качество поиска, календарная математика, анафора, бэкенд, E2E,
  legacy-роутер). Итого 107.

### Удалено (внешние ИИ-модули)

| Что | Почему |
|---|---|
| `GeminiBackend`, `OpenAIBackend` в `lumen/kernel/backends.py` | Требование «полностью своё ИИ, без API»: внешних генеративных модулей нет |
| `backend.overflow_provider` и гибрид-режим | Нет внешних модулей, которым передавать текст |
| Поля API-ключ/модель/URL в настройках UI | Ключи платформе больше не нужны |
| Авто-overflow в `core/model_router.py` (Gemini для «творческого» текста) | По умолчанию — только LUMEN Core |

Любое старое значение `backend.provider` (`gemini`, `openai`, …)
теперь приводит к LUMEN Core — конфиги не ломаются.

### Изменено

| Было (1.0) | Стало (1.1) |
|---|---|
| Основной модуль: `heuristic` (LHC) — шаблонный генератор | `lumen_core` (LUMEN Core) — единственный модуль: собственный ИИ с базой знаний, диалогом и вычислениями |
| Gemini / OpenAI — «генеративные модули наравне» | Удалены из платформы; генерация — только LUMEN Core, офлайн |
| 14 намерений в planner | 19 (+knowledge, joke, riddle, date_math, text_ops) + анафора |
| `math_handler` без ключа `ok` | Явный `ok: True` в успехе |
| Поиск по базе: равный вес всех токенов, стем 4 символа | Взвешенный (вопрос записи 3.0 > теги 1.5 > id 1.0 > ответ 0.5), стоп-слова, стем 4/5/6 — «что такое нейросеть» больше не отдаётся записям, где нейросети лишь в тегах; неизвестные темы не дают чужой факт |

### Сохранено

- `HeuristicBackend` / `provider=heuristic|lhc` — полностью
  совместимые алиасы LUMEN Core (старые конфиги работают).
- Legacy-десктоп (`main.py`): голосовой режим на стриминговом
  протоколе Gemini Live — отдельный legacy-продукт (режим
  «Desktop»), не ИИ платформы; текст legacy-действий по умолчанию
  идёт через LUMEN Core.

## LUMEN 1.0 — «Свет, который понимает»

Полная переработка проекта: создана самостоятельная ИИ-платформа **LUMEN**
со собственным ядром, интерфейсом, памятью и инструментами.
Брендинг предшествующих версий из проекта полностью устранён.

### Добавлено (новая платформа)

> Бренд-примечание: в таблице ниже «предшественник» — название модели
> предшествующей версии проекта. Оно в проекте более не используется;
> строка приведена только как историческая карта миграции.

- **`lumen/` — ядро LUMEN-1**:
  - конвейер «Луч» из шести стадий (`kernel/engine.py`);
  - защитный слой `ThreatGuard` — приём, лимиты, anti-injection (RU/EN);
  - `IntentPlanner` — 14 намерений, слоты, план инструментов;
  - `ContextWeaver` — персона + факты + история с бюджетом токенов;
  - `MemoryFabric` — 3 слоя памяти + авто-извлечение + импорт legacy;
  - `ToolRegistry` — схемы, таймауты, изоляция ошибок, доступность;
  - `LearningLoop` — фидбэк, адаптация предпочтений, экспорт корпуса;
  - `EventBus` — события конвейера.
- **Генеративные модули**: LHC (локальный, без сети), Gemini,
  OpenAI-совместимый (Ollama/LM Studio/…) + деградация на LHC.
- **Веб-интерфейс** `lumen/web/` — дизайн-система «Luminance»,
  разделы: Диалог, Инструменты, Память, Система, Настройки;
  живое отображение стадий конвейера (SSE), markdown-ответы, фидбэк.
- **REST/SSE API** `lumen/api/server.py` — stdlib, нулевые зависимости:
  чат, стрим, инструменты, память, сессии, настройки, система,
  фидбэк, обучение, здоровье, профиль.
- **CLI** `python -m lumen` — serve | chat | tools | status | memory.
- **Конфигурация** `config/lumen.json` — новый формат; авто-миграция
  API-ключей из legacy-конфига.
- **Документация**: README, `docs/ARCHITECTURE.md`, `docs/API.md`,
  `docs/BRANDING.md`, `docs/ROADMAP.md`.
- **Тесты** `tests/` — 60 тестов (ядро, память, инструменты,
  безопасность, обучение, API, SSE).

### Удалено (заменено новой платформой)

| Что | Почему |
|---|---|
| старая папка мобильного веб-приложения | Мобильное веб-приложение предшествующей версии — заменено единым отзывчивым интерфейсом `lumen/web/` (см. MOBILE_WEB_README.md) |
| `dashboard/` | Старый HTTP-дашборд (FastAPI) — заменён `lumen/api/` (stdlib) и новым UI |

| `config/certs/` | Сертификаты локального TLS (использовались только удалённым дашбордом) |
| `readme.md` (корень) | Документация старой версии — архив в `docs/legacy/old_readme.md` |

### Сохранено (совместимость)

- Конфиг-ключи `tts_jarvis_*` в `config/api_keys.json` продолжают
  читаться legacy-десктопом (имена ключей — часть пользовательского
  конфига; смена сломала бы существующие установки).
- `memory/long_term.json` — данные пользователя; импортируются
  в новую память при первом запуске (origin `legacy-import`).
- `actions/*` — модули действий; подключаются к ядру через
  legacy-мост `lumen/tools/adapters.py` (инструменты `legacy.*`).
- `main.py` / `ui.py` / `hub.py` — голосовой десктоп, переименован
  в LUMEN, позиционируется как режим «Desktop».
- `firmware/m5stick/`, `config/faces/` — без изменений.
